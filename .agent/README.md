# .agent Harness Index

This directory contains execution contracts for AI coding agents.

## Files

| File | Purpose |
|---|---|
| `HARNESS.md` | Required working loop for AI agents |
| `DOMAIN_BOUNDARIES.md` | Service ownership and data boundary rules |
| `EXEC_PLAN_TEMPLATE.md` | Plan template before non-trivial work |
| `CODEX_TASK_TEMPLATE.md` | Reusable prompt template for Codex/agents |
| `ACCEPTANCE_CHECKLIST.md` | Final review checklist |

## How To Use

1. Read `AGENT.md` at repo root.
2. Read `HARNESS.md`.
3. For non-trivial work, fill `EXEC_PLAN_TEMPLATE.md` mentally or in a task note.
4. Implement small changes.
5. Complete `ACCEPTANCE_CHECKLIST.md` before final response.
